💡 Tips for a Smooth Upload

  1. Keep column names exactly as listed in the template.

  2. Use ISO date format (YYYY-MM-DD) for all dates.

  3. Use numbers only for cost fields (no $ signs).

  4. Accessorials can be left blank if none apply.

  5. If some fields are missing (e.g., ContractRate), you can leave them empty — but filling them helps generate richer insights.
